Digital Techne Archivinfrastruktur
####################################################################################################################
DigitalTechne auf dem Internet Computer ist in Arbeit, die meisten Funktionen sind bereits vorhanden, während einige Funktionen in naher Zukunft verfügbar sein werden.

Es kann für viele verschiedene Anwendungsfälle angepasst werden, daher ist dies nur eine allgemeine Einführung.

Authentifizierung
============================================================================================
Die Authentifizierung erfolgt mithilfe der Internetidentität, die auf modernen Computern verfügbar ist (einige Hardwareunterstützung ist erforderlich). Bitte lesen Sie diese `Informationen <https://internetcomputer.org/internet-identity>`_ zur Internetidentität.

Es ist nicht nur sehr einfach zu verwenden, sondern auch sehr sicher und bietet im Grunde genommen ein vertrauenswürdiges Konto, in das keine Benutzeridentifikation integriert ist.

Wofür diese Plattform gedacht ist
======================================================================================================
Wenn Sie diese Seite lesen, wissen Sie bereits, dass DigitalTechne eine unzerbrechliche Verbindung zwischen etwas Physischem (dem Kunstwerk) und seinen digitalen Informationen herstellen möchte, und zwar mithilfe der besten Technologie: einer DNA-Tinte, die für jedes Kunstwerk einzigartig ist, und digitalen Informationen, die auf einer zuverlässigen Blockchain (dem Internetcomputer) gespeichert sind. Eine ausführliche Erklärung finden Sie im :download:`Pitch Deck <PitchDeck.pdf>`. 

Bitte beachten Sie, dass die BlockChain nicht nur die Textinformationen enthält, sondern auch alle Dokumente oder Bilder, die mit der Oper in Zusammenhang stehen.

So können Sie die Plattform nutzen
=========================================================================================================
Also:
* Sie besitzen ein Kunstwerk
* Sie möchten Ihr Eigentum daran sicher beurteilen
* Sie möchten alle Informationen und Bilder registrieren, die Sie für wertvoll halten

Sie können wie folgt vorgehen:
* Geben Sie die erforderlichen Mindestinformationen in die Blockchain ein (Autor, Name des Kunstwerks, Ort, Art des physischen Trägers, ein Bild)
* Laden Sie jedes gewünschte Dokument oder Bild hoch
* Kaufen Sie eine Tintenpatrone
* Platzieren Sie den Tintentropfen auf dem physischen Kunstwerk (die Patrone zerstört sich sofort nach Gebrauch selbst)
* Registrieren Sie den Tintencode in der Blockchain
* Sie können später weitere Informationen in BC hinzufügen
* Sie können die Echtheit des Kunstwerks jederzeit überprüfen:

* Entnehmen Sie mit einem Tupfer etwas DNA-Material aus dem Kunstwerk
* Geben Sie die DNA an ein genetisches Labor
* Laden Sie die Laborergebnisse auf DigitalTechne
* DigitalTechne zeigt alle Genomunterschiede zusammen mit der Position des Tropfens auf dem Grafik
