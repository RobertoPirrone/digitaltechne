Artwork Mark
##############################################

Inizialmente devi mettere l'inchiostro sull'opera d'arte. La posizione è importante, devi specificarla mentre inserisci i dati nella blockchain.

Dopo l'uso la cartuccia sarà inutile, il materiale del DNA verrà distrutto da una reazione chimica, per evitare un ulteriore utilizzo indesiderato

.. image:: ./lay_ink.png
  :width: 400
  :alt: Dossier

Si prega di notare che l'inchiostro è completamente trasparente a occhio nudo e, ovviamente, è stato progettato per una stabilità di lunga durata

.. image:: ./invisible_ink.png
  :width: 400
  :alt: Dossier

Utilizzando una lampada ultravioletta, la macchia di inchiostro sarà visibile

.. image:: ./visible_ink.png
  :width: 400
  :alt: Dossier

Inserisci in BlockChain
___________________________________________________________

E poi l'operazione blockchain: 
* seleziona dal primo menu a discesa l'identificativo della cartuccia di inchiostro
* seleziona dal secondo menu a discesa il lato dell'opera d'arte (fronte, retro o cornice)
* seleziona dal terzo menu a discesa la posizione di rilascio 

.. image:: ./bc_artwork_mark.png
  :width: 400
  :alt: Dossier

Alla fine di questa operazione blockchain apparirà un segno di spunta verde nella documentazione dell'opera
