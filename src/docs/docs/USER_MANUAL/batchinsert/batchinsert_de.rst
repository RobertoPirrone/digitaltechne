Stapeleinfügung
###########################################################################################

Dieser Vorgang ist für das Massenladen von Kunstwerken und Metadaten vorgesehen.

* Grundlegende Kunstwerkinformationen sind in einer Excel-Datei enthalten.
* Kunstwerke müssen im JPG-Format vorliegen.

Die Excel-Datei enthält die grundlegenden Informationen einer Oper, eine Zeile pro Kunstwerk. Kopfzeilennamen sind aussagekräftig, bitte verwenden Sie genau diese Namen:

* Fotos
* Datum
* Titel
* Technik
* Editionsnummer
* Abmessungen
* Einfügedatum (automatisch)
* Eigentümer (vom angemeldeten Benutzer abgeleitet)

Fotos enthalten nur die Nummer des Fotos, die dem tatsächlichen Dateinamen zugeordnet wird (z. B. ist 077 die Datei DSC_0077.JPG)
