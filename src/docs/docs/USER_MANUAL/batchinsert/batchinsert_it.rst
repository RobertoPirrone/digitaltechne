Inserimento batch
#############################################

Questa operazione è destinata al caricamento in blocco di opere d'arte e metadati

* Le informazioni di base sulle opere d'arte sono contenute in un file Excel
* Le opere d'arte devono essere in formato jpg

Il file Excel conterrà le informazioni di base di un'opera, una riga per opera d'arte. I nomi delle intestazioni sono significativi, si prega di utilizzare esattamente questi nomi:

* Foto
* Data
* Titolo
* Tecnica
* Numero di edizione
* Dimensioni
* data di inserimento (automatica)
* proprietario (dedotto dall'utente registrato)

Le foto conterranno solo il numero della foto, che verrà mappato sul nome del file reale (ad esempio 077 è il file DSC_0077.JPG)
