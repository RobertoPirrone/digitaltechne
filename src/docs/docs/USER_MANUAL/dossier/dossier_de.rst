Dossier
#####################################################################################

Auf dieser Seite werden Ihnen die im Archiv gehosteten Kunstwerke angezeigt. 

Jede Zeile enthält die wichtigsten Informationen zu einer einzelnen Oper (Titel, Autor usw.) sowie ein Bild

.. image:: ./dossier.png
  :width: 400
  :alt: Dossier

Jedes Kunstwerk besteht aus einer kleinen Anzahl von Papierblättern (der Hauptauflage, dem Exemplar des Künstlers, den unsignierten Exemplaren). Wenn Sie also auf das Bild klicken, gelangen Sie zu einer Seite mit einer Zeile für jedes physische Blatt eines einzelnen Kunstwerks

.. image:: ./dossiersingle.png
  :width: 400
  :alt: Dossier

Innerhalb dieser Listenseite führt ein Klick auf das Bild zu den detaillierten Informationen :ref:`Dossierdetail`

Ein grünes Häkchensymbol zeigt an, dass die Oper bereits mit DNA-Tinte versehen und die genomische Aufzeichnung in BlockChain aufgezeichnet wurde
