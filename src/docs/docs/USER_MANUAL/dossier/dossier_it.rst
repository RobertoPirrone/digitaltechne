Dossier
#######################################

Questa pagina ti mostrerà le opere d'arte ospitate nell'Archivio.

Ogni riga conterrà le informazioni principali su una singola opera (titolo, autore e così via), insieme a un'immagine

.. image:: ./dossier.png
  :width: 400
  :alt: Dossier

Ogni opera è composta da un piccolo numero di fogli di carta (la tiratura principale, la bozza dell'artista, le copie non firmate), quindi 
cliccando sull'immagine verrai indirizzato a una pagina con una riga per ogni foglio fisico di una singola opera

.. image:: ./dossiersingle.png
  :width: 400
  :alt: Dossier

All'interno di questa pagina elenco, cliccando sull'immagine verrai indirizzato alle informazioni dettagliate :ref:`Dettaglio dossier`

Un'icona di spunta verde indicherà che l'inchiostro del DNA è già stato applicato sull'opera e che il record genomico è stato registrato in BlockChain
