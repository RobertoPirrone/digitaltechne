Dossierdetails
##############################################################################################

Auf dieser Seite werden Ihnen alle Informationen zum Kunstwerk angezeigt:
* detaillierte Informationen
* eine Sammlung von Dokumenten

Durch Klicken auf jedes Dokumentsymbol können Sie die Datei herunterladen oder das Bild in voller Auflösung anzeigen

Mit der Schaltfläche **Kunstwerk mit DNA-Tinte markieren** können Sie die Verbindung zwischen der Tinte auf dem physischen Kunstwerk und seiner digitalen Darstellung (die auf dieser Seite angezeigten Informationen) registrieren. Einzelheiten finden Sie dort: :ref:`Kunstwerkmarkierung`

Wenn die DNA-Markierung bereits registriert ist, wird eine andere Schaltfläche angezeigt: **DNA-Markierung überprüfen**. Damit können Sie die Echtheit der Markierung überprüfen. Die beschreibende Seite finden Sie hier :ref:`Überprüfen`
