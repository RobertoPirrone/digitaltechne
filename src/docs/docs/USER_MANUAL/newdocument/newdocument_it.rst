Nuovo documento
############################################

Per descrivere meglio l'opera, di solito è molto utile aggiungere alcuni documenti, siano essi scientifici (analisi chimiche, ad esempio), legali (certificati di proprietà, ..), o artistici (studi, attribuzioni e così via).

I documenti possono essere aggiunti in qualsiasi momento e ogni record di documento contiene:

* il documento stesso
* l'autore del documento
* il titolo del documento
* il tipo di documento
* lo stato della privacy
* la data di inserimento (inserita automaticamente)
* la persona che ha inserito il documento (automatico)
* il nome del file (automatico)
* il tipo MIME (automatico)
