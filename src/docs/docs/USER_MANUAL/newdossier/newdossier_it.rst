Nuovo Dossier
###########################################

Il proprietario di un'opera d'arte creerà una cartella di informazioni in BC, contenente:

* Informazioni di base sull'opera d'arte (questa pagina)
* Documentazione di supporto (prova di proprietà, rapporto sulle condizioni e così via), vedere qui per l'inserimento dei dati :ref:`Nuovo documento`
* Informazioni sul DNA, vedere qui per i dettagli :ref:`Marchio dell'opera d'arte`

Le informazioni di base di un'opera sono principalmente:

* Immagine dell'opera d'arte
* Titolo
* Autore
* Ubicazione dell'opera
* Supporto fisico
* Alcuni flag per specificare il livello di privacy (proprietario, ubicazione, informazioni di supporto,...)
* Data di inserimento (automatica)
* Proprietario (dedotto dall'utente registrato)
