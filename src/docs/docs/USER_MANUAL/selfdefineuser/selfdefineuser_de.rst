Selbst definierter Benutzer
#####################################################################################################

Das Internet Computer-Framework bietet dank der Internet-Identität eine benutzerfreundliche und sichere Authentifizierungsmethode.

Ein neuer Benutzer wird beim ersten Anmelden automatisch registriert, mit eingeschränkten Möglichkeiten und ohne persönliche Informationen.

Das Einzige, was erforderlich ist, ist ein selbst definierter Benutzername. Muss im System nicht eindeutig sein
