Utente autodefinito
####################################################

Il framework Internet Computer, grazie a Internet Identity, fornisce un metodo di autenticazione amichevole e sicuro.

Un nuovo utente viene automaticamente registrato al primo accesso, con capacità limitate e nessuna informazione personale.

L'unica cosa richiesta è un nome utente autodefinito. Non deve essere univoco nel sistema
