## Development

Tools used in this project are (working directory .../src/frontend/):

- code formatting and linting: biome
- JS documentation (these pages): jsdoc
- JS hot reload: *npm start*
- Project documentation, manual pages: sphinx (working directory .../docs/) 

## Deploy

Follow the instructions in the shell scripts:
- to_local_fitst.sh for first time local deploy
- reame_money.sh for cycles realted info
- to_mainnet_fitst.sh for first time mainnet deploy
- to_local.sh for local deploy
- to_mainnet.sh for mainnet deploy
